# 表格数据检查与简报生成助手

面向班委 / 行政助理的单场景工具：上传**报名表 / 签到表**（CSV 或 XLSX），
自动完成数据质量检查、统计图表与文字简报生成，并可导出清洗后的数据副本。

## 功能一览

| 模块 | 说明 |
|---|---|
| 数据预览 | 上传即显示前 5 行与逐列健康度（非空 / 缺失率 / 唯一值 / 示例值） |
| 质量检查 | 必填缺失、唯一键重复、手机号（1 开头 11 位）、日期（YYYY-MM-DD）四类校验；错误精确定位到 **Excel 行号**（表头为第 1 行，首条数据在第 2 行） |
| 问题筛选 | 检查结果按 全部 / 缺失 / 重复 / 格式错误 分类 Tab 浏览，可导出错误清单 CSV |
| 统计图表 | 提交总数 / 有效 / 剔除指标卡，各组人数卡片与表格，交互柱状图 + 占比饼图，静态 PNG 可下载 |
| 自动简报 | 模板化 Markdown 简报（“本次共收到 N 份报名，其中 A 班 40 人，占比 42.1%…”），一键复制或下载 |
| 数据导出 | 清洗副本 XLSX（双工作表：有效数据 + 被剔除明细含原因）、简报 .md、柱状图 .png |
| 多 Sheet | XLSX 文件含多个工作表时可自选；CSV 自动探测 utf-8 / gb18030 编码 |
| 示例数据 | 无文件时可一键加载内置示例，立即体验全流程 |

**数据安全**：原始文件全程内存只读、不落盘、不修改；所有导出均为新生成的独立文件。

## 快速开始

```bash
# 1. 安装依赖（支持 Python 3.9 – 3.13，pip 会自动挑选与您版本匹配的依赖版本）
pip install -r requirements.txt

# 2. 启动
streamlit run app.py
# 浏览器自动打开 http://localhost:8501

# 或使用启动脚本（等价于上面两步）
bash run.sh
```

没有数据？点击侧边栏 **「加载示例数据」** 即可体验完整流程；
或用 `python sample_data/make_sample.py` 生成 1000 行含各类错误的 `sample_data/报名示例.xlsx`。

## 使用步骤

1. 侧边栏上传 CSV / XLSX（多 Sheet 文件可选择工作表）
2. 确认识别出的列配置：必填列、唯一键列（查重）、手机号 / 日期校验列、分组列
3. 点击 **开始检查**
4. 在四个 Tab 中查看：数据预览 / 检查结果 / 统计图表 / 简报与导出

## 运行测试

```bash
pytest tests/
```

覆盖加载、四类校验、行号口径、统计守恒、简报模板、导出结构与 Streamlit UI 集成流程。

## 项目结构

```
├── app.py                 # Streamlit 界面（唯一依赖 streamlit 的文件）
├── data_cleaner.py        # 读取 + 缺失/重复/格式校验（纯函数，可独立运行）
├── analyzer.py            # 分组统计、列健康度、matplotlib PNG 与 plotly 交互图
├── report_generator.py    # Markdown 简报生成与保存
├── requirements.txt
├── run.sh                 # 一键安装并启动
├── sample_data/           # 示例数据生成器与预生成的示例文件
├── tests/                 # 单元测试 + UI 集成测试
└── spec.md                # 开发方案文档
```

## 口径与规则说明

- **提交总数**：原始非全空数据行数；**有效记录**：通过全部校验且去重后的行
- 守恒关系：提交总数 = 有效 + 重复剔除 + 缺失/格式错误剔除
- 学号重复组保留 Excel 行号最小的一条，其余标记“与第 X 行重复”
- 分组统计基于有效记录，分组空值归入“未填写”；占比保留 1 位小数
- 手机号正则 `^1\d{10}$`；日期正则 + 真实日期双重校验（拦截 2025-02-30）

## 常见问题

- **CSV 打不开 / 乱码**：工具已自动尝试 utf-8 与 gb18030；仍失败时请用 Excel 另存为 .xlsx
- **图表中文显示为方块**：系统缺少中文字体，静态图自动回退英文标签；交互图表不受影响；
  安装任一候选字体（SimHei / Noto Sans CJK SC / WenQuanYi 等）即可恢复中文
- **性能**：1000 行数据校验 + 统计实测 < 0.1 秒
